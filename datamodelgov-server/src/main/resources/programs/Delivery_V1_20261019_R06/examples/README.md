# 示例使用说明

这里全部是合成数据、已保存历史结果或限定检查用模型，不是发动机真实试验结论，也不是本次组包重新计算的结果。正式使用时换成用户的数据和模型，另建输出目录。

| 目录 | 可以学习什么 | 使用边界 |
|---|---|---|
| `TC24/TestData` | 完整有效稳态窗口均值Excel字段 | sample_count按实际窗口填写，不照抄样例 |
| `TC24/MiddleData` | 两种确定性路径的模型交付结构 | 查看全部系数、调度与燃油偏置；不是强制初值 |
| `TC24/posterior_B`、`posterior_C` | 历史联合后验Excel及权重结构 | 只读教学，不冒充当前DLL下的新后验 |
| `TC27/TestData` | 原稳态点与完整试车历程的输入形式 | 具体稳态/过渡片段由用户新任务识别确认 |
| `TC27/TC27_UI_R065_20260928` | 已有稳态更新模型和identity | 模型与identity成套；不改签为本包运行 |
| `TC27/TC27_UI_R070_20261002` | 固定非零瞬态参数的组合模型交付 | 使用时显式选择来源和执行包，不清零13项参数 |
| `TC27_source_R018` | 上述组合模型对应的历史来源运行包与两类热资产 | 与当前执行包并存，不把旧DLL覆盖当前DLL |
| `F3/raw_training`、`raw_test` | 飞参训练与独立测试格式 | 测试集可选；真实用户不必复用任何架次名称 |
| `F3/R042_B1`～`R042_B4` | 已保存稳态飞参结果与配置/manifest | 是有限验证结果，不因已保存而等于已收敛 |
| `F3/TF_R002_continuous` | 过渡态模型、稳态载体和结果的配套关系 | 不能由此推断瞬态UQ已完成 |
| `Stage4` | 逐架次索引、两种预测模型和输出Excel | 只读格式例；原运行状态未完整复制，不声称可直接恢复整个历史任务 |
| `StartStop_public` | 一套真实生成的新设计公开保存包，包括热结果与设计参考 | 保持内部文件及manifest原字节；运行工作副本按起停手册产生 |

先用Excel查看工作表，或按各模块只读接口说明读取。不要从这个目录递归添加MATLAB路径，不要无参数执行样例目录中的Start文件。部分历史JSON/MAT内保留原运行绝对路径，用于追溯，不保证可作为新运行配置直接执行。

`StartStop_public`内带的是该历史包自己的源码快照和配套设计参考，不与主程序根同名文件互相替换。当前公开入口读取后创建独立运行副本；本次只核清单字节，换目录冷消费属于7.4。源文件位置、SHA与包内目标见`manifests/material_sources.csv`。

完整业务入口、自己如何配置、输出怎么看、调试顺序分别见[业务导航](../docs/02_业务与接口导航.md)与[部署和调试](../docs/01_部署调用与调试.md)。
