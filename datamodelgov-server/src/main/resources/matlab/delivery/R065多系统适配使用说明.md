# R065多系统联合仿真：独立运行和界面调用

## 1 本次增加了什么

使用R06原有模型`Dll_Control_AFO_V8_5_R2019b.slx`。原247个采集标量不删不改，在末尾增加燃油代理11项内部量和空气14项供气温压，共272项原始记录；Excel另保留4项原有派生回退标志，共276项。界面显示111项，由`sht_afo_display_channels.csv`明确选择，不把全部采集量都画出来。

环境仍为Windows x64、MATLAB R2019b、Simulink和原已确认的VC2010 DLL加载环境。无网络运行，不依赖GUI、Optimization Toolbox或Statistics and Machine Learning Toolbox。不要把本目录和其他AFO版本同时加到MATLAB路径。

## 2 独立运行

在MATLAB中把当前目录切换到本包`程序/programs/AFO_V_2`，执行：

```matlab
cfg = sht_afo_config();
cfg.engineId = 'ENGINE-USER-01';
cfg.runId = 'TEST-USER-01';
cfg.outputDir = fullfile(pwd, 'my_results', 'test_001'); % 必须是尚不存在的新目录
cfg.duration = 30;          % 秒，必须落在0.025秒积分网格
cfg.recordStep = 0.1;       % 秒，必须是0.025秒的整数倍
cfg.pace = 'fast';          % fast尽快计算；realtime约按真实时间推进
cfg.externalAir = false;    % 仅控制空气流量回灌，不关闭空气系统本身
cfg.plots = false;
result = Start_AFO_Multisystem(cfg);
view = Start_AFO_ResultView(fullfile(cfg.outputDir,'AFO_results.xlsx'));
```

`result.time`与`result.values`对应每个实际记录时刻。`result.catalog`给出扁平列ID、单位、来源、显示分组和物理含义。`state='ended'`只表示数值执行结束，保存是否完成看`status.saveState`，不能混为一个状态。

界面按`display`筛选，再按`displayGroup`和`panel`组织页面。`group`保留旧采集来源，不等于界面分组：例如燃油指令和发动机实际燃油在历史采集分组中属于fuel，但本版显示在control。111项由发动机20、控制8、燃油代理12、滑油47、空气24组成。其他原始记录没有删除，只是不在本版业务通道树中展示。

Np保留80%、90%、95%、100%、105%五挡。负载可选`power`、`torque`、`pitch`或`dual_pitch`，配置分别使用`powerW`、`mkpNm`、`pitchDeg`或`mainPitchDeg/tailPitchDeg`。功率单位W，扭矩N·m，总距角deg。双桨仍为现有工程等效负载关系，不是独立旋翼动力学模型。

准备初态仍为配套MDL的正转速初态；若初始指令不同，必须设置`cfg.initialTransitionConfirmed=true`，其含义是允许从配套初态过渡，不能解释为目标状态已配平。不能在此入口配置起动停车。

## 3 运行中控制

同一MATLAB进程中的轻量观察回调可以调用：

```matlab
s = sht_afo_session('status');
sht_afo_session('pause');    % 请求暂停；state真正变paused才算生效
sht_afo_session('resume');   % 同一Simulink实例继续，无重新初始化
sht_afo_session('command',struct('id','load_001','kind','load','value',1.5e6));
sht_afo_session('stop');     % 结束计算，不是发动机物理停车/切断燃油
```

同步`run`调用期间，主命令行被占用；以上操纵应放在观察回调中，或由另一个进程通过下面的文件命令投递。不要以为同步执行期间还能在同一被占用命令行自由输入命令。

暂停时新负载只排队，恢复后的主步才生效。一次只允许一项未生效物理命令。重复相同命令ID和内容不会重复施加，同ID不同内容被拒绝。`acceptedTime`为接收时间，`appliedTime`为真正施加时间；两者不得混用。

## 4 界面工作进程

界面启动一个专属MATLAB工作进程运行：

```matlab
cfg = sht_afo_config(fullfile(pwd,'my_results','ui_001'));
cfg.duration = 30;
cfg.pace = 'realtime';
result = Start_AFO_Worker(cfg);
```

此函数计算结束后继续保留原进程中的结果，等待用户保存重试或关闭确认。它共用`sht_afo_session`，没有第二套仿真算法。不会自动重跑，不会因Excel被占用就丢弃结果。

在另一MATLAB进程或实现同一JSON合同的界面中：

```matlab
folder = '本次运行输出目录';
sht_afo_submit(folder,struct('id','pause_001','kind','pause','value',0));
sht_afo_submit(folder,struct('id','resume_001','kind','resume','value',0));
% 计算已经结束，保存失败解除后：
sht_afo_submit(folder,struct('id','save_001','kind','save','value',0));
% saveState真正变为saved后，用户确认关闭：
sht_afo_submit(folder,struct('id','release_001','kind','release','value',0));
```

`release`在未保存时拒绝。用户明确决定放弃未保存结果时才用`discard`。数值程序无需界面也能通过同一方式管理。可选第三参数`Start_AFO_Worker(cfg, observer, serviceSeconds)`仅限制计算结束后的管理等待；到时返回调用者但保留会话，不等于已释放。正式工作进程默认无限等待显式关闭。

外部命令必须携带`runId`和随机唯一`sessionId`；`sht_afo_submit`从本次状态补齐并校验。第三方应在连接时锁定该会话身份，而不是每次悄悄绑定另一个运行。结果目录不允许复用。`processed_commands/<id>.json.receipt.json`会更新至最终状态；不能只看文件投递成功。

## 5 动态历史与断线补读

```matlab
q = sht_afo_read_live(folder, 0); % 首次最多2048行
sessionId = q.status.sessionId;
cursor = q.nextSeq;
q2 = sht_afo_read_live(folder, cursor, sessionId, 2048);
```

`sampleSeq`是记录序号，`sampleTime`是该行物理输出对应时刻。`values`列顺序来自`catalog`，不是按固定长度猜测。`currentSimulationTime`是当前推进时刻，可比最新记录时刻稍晚；不能拿它给旧值重新标时间。

`nextSeq`记录本次已读到哪里；`hasMore=true`时继续读取积压。`isFinal=true`表示已读到计算终态全部记录，不表示Excel已经保存。界面关闭、缩放或换页不影响采样；重连使用原游标补读，不丢弃中间点。历史只读文件，不加载DLL或SLX。

`quality`逐样本逐列标记：0有限原始值；1非有限；2该负载模式不适用；3单位未确认。非有限值在JSON中为null，在MATLAB读取为NaN，不以零代替。单位未知量可看原始趋势，但不能做单位换算或与其他温度直接比较。

`publishLive=false`关闭增量数据发布，但仍完整采样并导出Excel。默认每0.2秒墙钟或积累128条样本发布一批，单批上限可配置；它不改变积分步长和记录频率。暂停时只更新心跳，不产生样本。提前结束保留真实末主步；终点不在记录网格时增加一个真实尾样本。

文件合同：`channels.json`为字典，`status.json`为最新状态，`stream/*.json`为不可变样本块；临时文件写完才发布。流与状态发布失败不会删除内存结果，`publishError`报告失败，未发布序号下次重试；界面以心跳过期区分失联，不宣称后台已停止或已恢复。硬盘满、网络盘原子改名行为等仍需部署机验证。

全部JSON文件明确使用UTF-8。MATLAB R2019b下应使用`sht_afo_read_json(file)`或本节的正式读取器，不要直接组合`jsondecode(fileread(file))`依赖系统默认编码。中文目录和错误信息中反斜杠遇到默认CP936解码时可能导致JSON解析失败，本轮已经修复并验证这一边界。第三方界面也必须显式用UTF-8读取，并将无效编码与合法的中文文本区分。

## 6 保存、结果和故障排查

Excel的Data保留原列并增加25项，Channels保留原7列并增加显示分组及物理含义，Run/Identity/Config/Commands保留历史用途。新结果合同为`SHT_AFO_RESULT_V2`，读取器兼容R06的V1。旧文件不存在的新量显示未记录，不补造。

独立入口导出失败抛出明确异常，但原MATLAB中的`sht_afo_session('result')`仍可读取；解除文件占用后执行`sht_afo_session('save')`。不要清空MATLAB函数或结束进程后再要求从未保存动态状态续算。工作进程入口会捕获该异常并继续服务保存请求。

若曲线不动：先看`state`、`sampleSeq`、心跳和`publishError`；有些燃油压差本来就是常值，不可人为添加波动。空气多路供气共源时重合正常，但仍需分别保留通道身份。所有供气温压是当前原SLX实际连接值，不说明原空气网络已全面校准。

若数值失败：查看`stopReason`、原MATLAB日志和部分Excel；若仅`saveState='failed'`，这是保存失败，不是数值求解失败。观察回调失败记录为`observerError`并停用回调，数值继续；界面可重新通过文件连接。

本轮短测覆盖和未覆盖项见R065测试报告；新环境仍须验证许可、VC2010加载及真实离线运行。本说明不承诺当前机器测试等同目标隔离机验收。

`manifests/package_files.csv`为程序和说明清单，`delivery_files.csv`为全工作副本清单。`tools/Verify-Delivery.ps1`校验SHA256并报告R065，不会启动数值计算。`R065_validation`目录保存本轮分批检查结果与源文件清单；原始运行模型、Excel、日志、失败和休眠证据保存在界面分支UI_R141的QA目录，供MAIN追溯，不是普通运行依赖。
