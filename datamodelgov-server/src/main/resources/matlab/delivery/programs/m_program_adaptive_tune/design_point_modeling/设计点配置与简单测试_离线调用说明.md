# 设计点配置与简单测试：界面和独立离线调用

目标环境：Windows x64、MATLAB R2019b、项目已确认的DLL/头文件和VC2010加载环境。无需Optimization Toolbox或Statistics and Machine Learning Toolbox。不是脱离MATLAB的独立可执行文件。

## 1. 两个入口

原`RunModelSHT_V1_2DP.m`和`RunModelSHT_V2_2DP.m`保留原样，继续用于原手工配置流程。新增入口为：

- `RunModelSHT_V1_2DP_Auto`：三部件，只使用`Turboshaft-TS.mdl`。
- `RunModelSHT_V2_2DP_Auto`：六部件，只使用`Turboshaft-TS-Split.mdl`。

两者默认**只求解和测试私有候选，不写正式MDL**。GUI使用相同`sht_design_point_task`核心，不能另写求解算法。

```matlab
addpath('本模块目录');
cfg = sht_design_point_config(0); % 0三部件，1六部件
cfg.sourceDirectory = '所选MDL及其MAP目录';
cfg.codeDirectory = 'GTESS.dll、三头文件、加载助手及stdio头所在目录';
cfg.taskDirectory = '一个尚不存在的任务目录';
cfg.engineId = 'ENG001';
% cfg.design中集中编辑设计目标；cfg.solver中编辑初值/数值设置。
r = RunModelSHT_V1_2DP_Auto(cfg);
% 六部件改用cfg.modelMode=1对应的配置构造与V2_Auto入口。
```

目录参数请使用明确的绝对路径。正式安装位置为`tune/design_point_modeling`时，设计点配置的默认源与代码目录均为其父目录`tune`；不默认指向本轮开发工作树。建议为每次设计显式选择独立任务目录，并将模型资产、计算记录和报告分别保存在该任务的TestData、MiddleData、report_outputs中。

`codeDirectory`至少包括`GTESS.dll`、`GTESS.h`、`blockAndFunctions.h`、`types_TMATS.H`、`sht_load_engine_library.m`和`matlab_loadlibrary_include/stdio.h`。私有副本中产生桥接文件，不能向只读源目录写桥接，也不能用另一版本头文件配DLL。

三部件未知量仍为流量、HPC Rline、GT/PT压比、Np/Ng和燃油，共7项。六部件仍为原12项设计变量；2/25/3截面目标和级功率分配集中给出，临时校准量折算到MDL的设计字段/缩放系数，不成为运行健康修正。

## 2. 明确写入与简单测试

```matlab
disp(r.parameterComparison);             % 查看原值和本次计算值
r = sht_design_point_task('commit', r.taskDirectory);
% 此时才修改原先选定的MDL，并打印原字节备份路径。
Start_DesignPoint_SimpleTest(r.taskDirectory, 'committed');
```

`commit`是显式写入指令。先核源MDL/MAP/DLL/程序身份，再创建`原名.backup_年月日_时分秒毫秒_唯一后缀`，校验备份SHA后写入。提交过程中不改变另一拓扑、MAP或DLL。写入后从实际目标重新复制并加载，在`offDesignMode=2`复现。本轮开发测试只对私有模拟目标执行，不自动改变主工程的正式默认配置。

已被其他任务修改的文件、缺失/重复字段、未通过候选复现和旧程序身份会明确拒绝覆盖。提交后测试失败保留备份和失败记录，不能把写入成功当数值通过。恢复备份需用户明确操作，不自动删掉失败现场。

## 3. 起停建模与简单测试

```matlab
u.adapterDirectory = '已核定起停建模适配器目录';
u.codeDirectory = '已核定起停算法核心及其依赖目录';
u.taskDirectory = '新的起停简单测试目录';
u.showFigures = false;
q = Start_StartStopModeling_SimpleTest(r.taskDirectory, u);
```

先检查本次设计身份，再复用现有适配器生成私有低速图、检查原工作域、运行9点低速共同工作矩阵。设计Np、Ng、喷口面积和有关功率边界由本次设计传入。9点为Ng设计比20%、30%、65%，Np设计比为相应Ng比的0.6倍，各有无燃油、点火前和低燃油三状态。不是固定轴速的连续起动，也不进行自动调图搜索。

设计点通过不保证低速全部通过。每点保留原收敛标志、残差、物理状态和图域风险，不删失败点、不放宽精度。摩擦、惯量、起动燃油等仍是可见工程先验；它们没有随设计点求解自动标定。连续起动、暖机、停车和热校核仍由原起停建模入口显式执行，有限9点不代替这些校核。

## 4. 保存与读回

每个设计任务独立保存：

- `TestData/configured_model`：本次模式2运行配置及配套MAP/DLL/头。
- `MiddleData/design_task.mat`与`design_state.mat`：本次设计输入、求解和复现参考，不读取历史latest。
- `report_outputs/design_parameters.xlsx`：全部待写参数原值/计算值和设计目标。
- 明确提交后，原MDL旁保留时间备份；任务记录关联写入前后SHA及复现结果。

```matlab
r = sht_design_point_task('inspect','任务目录'); % 无DLL、无需再次计算
```

### Excel重新导出

已保存计算结果可以不调用DLL直接重新导出：

```matlab
r = sht_design_point_task('export','实际任务目录','本次导出目录');
disp(r.export);
```

省略第三个参数时导出到实际传入任务目录的report_outputs。程序先完整写入MDL_Parameters和DesignTargets两个工作表，再替换目标Excel。文件被占用或路径冲突时保留旧工作簿及原MAT，返回`r.export.status='failed'`和具体error；解除占用后重试export，不需要重新求解。`r.status`仍表示原计算结论，不与导出状态混用。

导出回执单独保存在新输出目录的`design_export_*.json`，包括原MAT身份、输出文件、本次耗时和错误。回执自身写入失败时查看返回结构的receiptError。显式export不会修改旧design_task.mat或codeIdentity，因此后续inspect不能代替查看最近一次导出回执。搬迁历史记录时应传实际任务目录并显式选择新输出目录，不执行记录中的旧模型。

inspect/export允许只读旧版本结果，但缺少实际参数表或设计目标时返回缺字段错误，不从现行默认配置补值。commit/test/validate仍保持原严格身份核对，不因允许旧结果导出而允许旧记录重新计算或写入。

起停简单测试另存逐点Excel、MAT及原矩阵证据，不伪造原起停适配器未执行阶段的通过标记。MDL/MAP/运行配置是运行资产，不能只交一份参数Excel就声称模型可独立仿真。源文件变化后建立新任务，不给旧检查点改签。
